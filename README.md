# 障害者控除いくら？（shogai-ikura）

本人・同一生計配偶者・扶養親族の障害のようすを読んで、障害者控除の額を当てる1日5問の学習ゲーム。正解したら「どの決まり？」（障害者・特別障害者・同居特別障害者・2人以上を足す・対象にならない）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/shogai-ikura/>

- 答えは、国税庁のタックスアンサーの決まりから出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）（障害者は1人27万円・特別障害者は1人40万円・同居特別障害者は1人75万円。何人かいれば1人ずつ足す。施設に入所している人は同居に当たらない。本人は同居特別障害者にならない）。
  - No.1160 障害者控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1160.htm>
- 対象は本人・同一生計配偶者・扶養親族（16歳未満の扶養親族も入る）です。税額・障害者の区分の細かいところ・住民税・申告の手続きは出しません。人と年齢はつくりものです。
- このゲームは障害者控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
